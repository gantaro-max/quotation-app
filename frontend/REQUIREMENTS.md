# 見積作成システム 要件定義書

- **ドキュメント作成日:** 2025 年 12 月 17 日
- **対象システム:** Web ブラウザベース見積作成アプリケーション

## 1. システム概要

本システムは、営業担当者がブラウザ上で効率的に見積書を作成・編集・印刷、保存するための業務アプリケーションである。
Excel ライクな操作性（キーボード移動、コピペ）と、リアルタイムなプレビュー機能（WYSIWYG）を兼ね備える。

## 2. 業務フロー・ユーザー

- **利用者:** メディカル担当者（各拠点に所属）
- **利用シーン:**
  1.  ログインを行う。
  2.  過去の見積を検索・参照する、または新規作成を行う。
  3.  見積内容（明細）を入力する。
  4.  印刷プレビューを確認し、PDF 保存または印刷を行う。

## 5. UI/UX・非機能要件

1.  **レスポンス:** 入力に対する計算・プレビュー反映は遅延なく（同期的）に行うこと。
2.  **レイアウト:**
    - **画面分割:** 左側 55%（入力エリア）、右側 45%（プレビューエリア）の 2 ペイン構成。
    - **印刷:** ブラウザ印刷機能を用いた際、A4 用紙サイズに正しく収まること（CSS `@media print` 対応）。
3.  **入力制御:**
    - 数値項目は半角変換およびカンマ除去を自動で行う。
    - Enter キー、矢印キーによる Excel ライクなフォーカス移動を実現する。
4.  **互換性:**
    - Excel 等の表計算ソフトからコピーしたタブ区切りテキストを、明細グリッドに貼り付け可能とすること。

## 6. 今後のロードマップ・技術選定

### 6.1 バックエンド構築

- **技術スタック:** Java (Spring Boot) + MyBatis + MySQL
- **連携方針:**
  - 本フロントエンド実装完了後、REST API サーバーを構築し連携を行う。
  - 現在のモックデータ部分を API コールへ置き換える。

### 6.2 排他制御・データアクセス方針

- **アクセス制限:**
  - 見積データの参照・編集・検索は、**「作成したユーザー本人」のみ**に限定する仕様とする。
  - これにより、複数人が同一データを同時に編集する競合状態（コンフリクト）を回避するため、システム側でのロック機構（悲観ロック・楽観ロック）の実装は行わない。

### 6.3 マスタ管理機能

- **CSV 更新:**
  - 商品マスタや得意先マスタ等の参照系データについて、画面からの個別登録機能ではなく、CSV ファイルによる一括インポート/更新機能を将来的に実装する。

### 6.4 その他

- **OCR 機能:** 実装未定（UI 上のボタンは配置するが、バックエンド機能実装は当面見送り）。
